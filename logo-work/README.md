# Skye logo directions

Working name: **Skye** (also considering Skai, skydea).

Peer UX testing for students — credit economy. Idea: blue sky / cloud. One colour, mark + wordmark, mark must stand alone.

## Deliverable

- `book/logobook.pdf` — six directions to choose from
- `directions/` — recipes
- `build/` — SVG mark, wordmark, lockups per direction
- `brief.json` — answers from the intake

## Traced directions (close to moodboard on purpose)

- **Twin sky** — traced from moodboard twin-ascent, with a circular sky bite
- **Flight cut** — traced from moodboard flight-plane, with a sky bite

These are marked in the book. Passing the distance check is not a trademark clearance; each package includes a search sheet after you pick.
